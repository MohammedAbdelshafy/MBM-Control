# AI Workflow Pilot — Buyer One-Pager

## The offer

**One workflow. $750. Measured before/after.**

We take one recurring business workflow and test whether AI-assisted execution can reduce manual effort or improve throughput while keeping a human QA checkpoint.

## Good pilot candidates

- sales intake or qualification
- CRM / account handoffs
- repetitive reporting
- engineering tickets and documentation
- QA / triage workflows
- customer-service intake and routing
- evidence collection and structured summaries

## What happens

**1. Baseline**
Map the current workflow and identify the measurable bottleneck.

**2. Pilot**
Implement AI-assisted steps around the existing process.

**3. Human QA**
Keep an explicit review checkpoint instead of pretending the model is infallible.

**4. Measure**
Compare the agreed baseline against pilot results.

**5. Decide**
Keep, expand, change or stop based on the evidence.

## Deliverable

A completed pilot with:
- workflow map

- QA checkpoint
- measurement summary
- next-step recommendation
