# One Episode → A Week of Distribution

## The problem
A podcast, webinar, interview, or long-form YouTube episode can contain dozens of usable moments, but the work after recording is still fragmented:

**find the moment → edit → caption → review → upload → write copy → schedule → publish → measure**

The result is a familiar bottleneck: the team has content, but not enough distribution capacity.

## The offer
MBM can run a paid pilot around one real content workflow:

**Long-form source → AI clip candidates → captions → QA → content calendar → scheduled publishing → analytics**

The pilot is designed to measure the workflow, not sell magic.

### What we measure
- Source-to-first-clip turnaround
- Usable clips produced
- Posts scheduled
- Manual handoffs removed
- Publishing completion
- Performance data captured for the next cycle

## Best-fit buyers

3. Creator/media agencies managing multiple accounts
