# Quick Revenue Search Factory

Purpose: give every MBM revenue-capable factory a fast, repeatable commercial scan before new build work.

## Universal input
- Existing asset or workflow
- Buyer/problem hypothesis
- Current proof or demo
- Known deployment state
- Known blockers

## Search sequence
1. Search current buyer demand and pain signals.
2. Identify buyer categories and likely decision-maker roles.
3. Verify the company/workflow with authoritative or primary sources when possible.
4. Find comparable products, services, and proven market patterns.
5. Extract the smallest credible paid offer.
6. Record price hypothesis, delivery path, proof requirement, and next action.
7. Feed the result into the Revenue Radar.

## Factory lanes
- Visual AI Evidence Engine: warranty, inspection, field service, support, returns.
- Lead Cleaner: data cleaning, enrichment, verification, CRM hygiene.
- Creator Factory: short-form production, repurposing, creative operations.
- Construction AI: BOQ review, estimation, document intelligence, field evidence.
- ERP / Contec: accounting, project operations, procurement, reporting.
- Developer Factory: agents, MCP, integrations, implementation services.
- CAD / Masterplan: automation, drafting, planning, engineering deliverables.
- Existing Apps: productized app licenses, setup, customization, white-label.
- Digital Products: templates, kits, playbooks, datasets, workflow packs.
- Revenue / Agent Systems: orchestration, dashboards, automation, intelligence.

## Output schema
`asset`, `buyer_problem`, `demand_signal`, `buyer_role`, `evidence_source`, `offer`, `price_hypothesis`, `proof_needed`, `delivery_path`, `blocker`, `next_action`, `timestamp`.

## Operating rule
Search first, build second. Existing revenue-capable assets move to SELL mode before non-blocking engineering.

Never claim demand, a qualified buyer, a sale, publication, deployment, or customer result without evidence.
