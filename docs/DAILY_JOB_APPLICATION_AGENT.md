# Autonomous Job Application Operating Policy

## Objective
Maximize legitimate foreign-currency job/client revenue by finding and applying to high-value opportunities that can be performed from Egypt.

## Priority
1. US, Canada, Switzerland, Sweden, UK, and Europe.
2. Worldwide-remote or Egypt-compatible contractor/freelance engagements.
3. USD first, then strong EUR/CHF/GBP.
4. AI agents, LLM applications, automation, Python, full-stack, AI integration, lead/data intelligence, SaaS, developer tools, technical operations.
5. Fast-to-cash freelance/contract work and direct clients.
6. Prefer $750+ project budgets or strong hourly/annual compensation.

## Autonomous application rule
The agent may submit an application when:
- the platform is authenticated;
- the platform exposes a real submission mechanism;
- the role passes geography/remote/work-authorization checks;
- the proposal is tailored;
- duplicate application protection is satisfied.

The tracker status must remain "saved" or "ready_to_apply" until successful submission is confirmed. Never mark an application as submitted merely because an application page was opened.

## Current platform state
- FoundRole: authenticated search and tracking available; application submission tool is not exposed.
- Upwork: browser access currently reaches the login page, so no authenticated submission can be performed.
- No credentials or secrets are stored in GitHub.

## Follow-up
After a confirmed application:
- follow up after roughly 3-5 days with no response;
- stop after reply, closure, or rejection;
- record each contact and result.

## Prohibited
- No use of Contec company email.
- No fabricated application status.
- No duplicate applications.
- No submission when Egypt eligibility is unclear for a location-restricted role.
