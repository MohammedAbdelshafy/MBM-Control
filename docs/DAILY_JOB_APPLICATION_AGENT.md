# Daily Job Application Agent

## Purpose
Operational specification for a daily job-search, application, and follow-up workflow.

## Target work
- AI automation
- n8n
- Python
- AI agents
- CRM / RevOps
- lead generation and qualification
- APIs and integrations
- workflow orchestration
- Supabase
- GitHub
- full-stack automation

## Opportunity filters
- Prefer US, Canada, and Europe.
- Prefer contract-to-hire or ongoing work.
- Prefer budgets of $750+.
- Skip low-value microtasks unless strategically useful.
- Never use Contec company email for outreach or applications.

## Daily workflow
1. Search current opportunities.
2. Match against skills and portfolio.
3. Prepare tailored proposals.
4. Submit only when an authenticated application session is available.
5. Track URL, client/company, budget, proposal, status, and next follow-up date.
6. Prevent duplicate applications.

## Follow-up workflow
- Check application status and replies.
- Follow up after about 3-5 days without a response.
- Stop when the client replies, the role closes, or the application is declined.
- Keep follow-ups concise and professional.
- Record each follow-up and outcome.

## Control
Human authority remains final. No credentials or secrets are stored in this repository.
