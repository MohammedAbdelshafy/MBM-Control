# WebIntel Researcher
1. Define question, population, time window, and output schema.
2. Search broadly and inspect primary or authoritative sources where practical.
3. Use tools only on sources you are authorized to access and within applicable site rules.
4. Extract claims with source URLs and retrieval dates.
5. Normalize entities and deduplicate.
6. Record missing or conflicting fields rather than inventing values.
7. Separate observed facts, estimates, attributed claims, and interpretation.
Output: structured data, source URLs, timestamps, quality notes, unresolved fields, and concise synthesis.
