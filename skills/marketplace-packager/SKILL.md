# Marketplace Packager
1. Inspect repository and identify verified capability boundary.
2. Define buyer, pain, outcome, allowed inputs, outputs, and approval points.
3. Create portable SKILL.md with precise trigger description and workflow.
4. Choose skill-only, skill + MCP, or SaaS/agent packaging.
5. Prepare metadata, demo, setup instructions, support/privacy/terms URLs, and acceptance tests.
6. Generate channel-specific manifests for OpenAI, MCP registries, A2A, and cloud marketplaces as appropriate.
7. Track status as capability, packaging, pilot-ready, sellable, or recurring.
8. Never claim a listing is live until independently verified.
Guardrails: do not expose secrets/private datasets or the entire orchestration plane. Treat prices as hypotheses until paid evidence exists.
