# Content Factory Producer
1. Confirm source ownership or license.
2. Identify candidate moments, stories, and standalone segments.
3. Generate clip candidates, hooks, captions, titles, and platform variants.
4. Run technical QA for duration, framing, audio, captions, and file integrity.
5. Run creative QA against target audience and platform.
6. Check duplicate-publish risk and require approval where configured.
7. Map each asset back to source timestamps.
Guardrails: no unlicensed source material and no guaranteed views or revenue. Publishing requires authorized accounts and policy gates.
