# Groq Fast Inference Skill

**Goal**: Execute low-latency, 500+ tokens/sec inference for real-time agents, live telephony copilot scripts, and engineering audit verification.

## Model Selection Matrix:
- `llama-3.3-70b-versatile`: General conversation, structured JSON extraction, rapid script generation, multi-turn dialogue.
- `deepseek-r1-distill-llama-70b`: Deep mathematical validation, multi-step structural reasoning, contract logic analysis.
- `llama-3.2-90b-vision-preview`: Multi-modal visual reasoning on CAD plans, site photos, and architectural blueprints.
- `whisper-large-v3`: Real-time audio transcription with sub-second latency.
