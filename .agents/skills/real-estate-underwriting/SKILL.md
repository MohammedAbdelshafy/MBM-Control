# Real Estate Underwriting Skill

**Goal**: Underwrite distressed residential and commercial off-market assets into institutional investment dossiers for private equity funds and fix-and-flippers.

## Metrics & Formulas:
- **After Repair Value (ARV)**: Triangulated from 3 recent MLS comps within 0.5 miles.
- **Maximum Allowable Offer (MAO)**: $\text{MAO} = (\text{ARV} \times 0.70) - \text{Rehab Budget}$.
- **Projected Wholesale Spread**: $\text{Wholesale Fee} = \text{MAO} - \text{Contract Price}$.
- **Unlevered Investor ROI**: $\text{ROI} = \frac{\text{Net Profit}}{\text{MAO} + \text{Rehab}} \times 100\%$.
- **Distress Vector Scoring**: Absentee ownership, tax delinquency, code violations, probate status.
